# v2rayN Modern UI Redesign

A UI/UX redesign of v2rayN focused on improving usability,
visual hierarchy, accessibility, and day-to-day workflow while
preserving the full functionality of the original application.

## Design principles

- Preserve all existing functionality
- Reduce visual complexity, not capability
- Improve information hierarchy
- Keep power-user workflows fast
- Maintain compatibility with upstream v2rayN
- Use reusable design tokens and components

## Themes

- Graphite Blue
- Midnight Violet
- Neutral Teal

## Status

Design approved. Implementation in progress.
